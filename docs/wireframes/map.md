# Wireframe map

Open `/wireframes` for the grey boxes.

Chat is a left thread rail and a 720px column. The composer sits at the bottom of that column.

Space is five regions: top bar, left tabs (Agent, Library, Layers), canvas, right inspector, bottom navy tool dock.

Admin is a page title plus a table or a two-column review.

The small-screen canvas is view only. Chat, library, queue, and settings stay usable at 390px.
